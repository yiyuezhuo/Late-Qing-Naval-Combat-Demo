## M79APCLC

Nathan Okun's homogeneous armor penetration program.

- Documentation page: [M79APCLC documentation](https://www.navweaps.com/index_nathan/M79apdoc.php)
- Download package: [M79APCLC.zip](http://www.navweaps.com/index_nathan/M79APCLC.zip)

Expected local contents after extracting to `References/M79APCLC`:

- `M79apclc.bas`
- `M79apclc.exe`
- `M79lprnt.bas`
- `M79lprnt.exe`
- `M79APCLC.zip`

## NAaB2

Steven Lorenz's Naval Armor and Ballistics 2.x Windows program. Its instruction
PDF describes it as a Borland Delphi program combining Robert McCoy's MCTRAJ
ballistics logic with Nathan Okun's FACEHARD and NCWCLCR/HCWCLCR armor
penetration logic.

- Original page: [NAaB page](http://www.panzer-war.com/Naab/NAaB.html)
- Download package: [NAAB2x.zip](http://www.panzer-war.com/Naab/NAAB2x.zip)
- Matrix Games reference thread: [NAaB 1.0 - Naval Armor and Ballistics program](https://forums.matrixgames.com/viewtopic.php?t=131949)

Expected local contents after extracting to `References/NAAB2x`:

- `NavalArmorBallistics.exe`
- `Naval Armor and Ballistics Instructions.pdf`
- `DRAGFACT.DAT`
- `ProjInfo.txt`
- `ProjNation.txt`
- `ProjSelections.txt`
- `BombInfo.txt`
- `NAAB.LNG`
- `FILE_ID.DIZ`
- `90mm76mmvsFHRHA.jpg`

## FaceHard69

files.

- Index page mirror: [Nathan Okun Naval Gun and Armor Data Resource](https://www.warship1.cn/navweaps/index_nathan.htm)
- Download package: [Facehard69.zip](https://www.warship1.cn/navweaps/Facehard69.zip)

- `FH69SBM1.BAS`
- `FH69SBM2.BAS`
- `FH69MAIN.MAK`

## Exterior Ballistics Book Reference

The exterior-ballistics notes in the manual refer to Robert L. McCoy's
_Modern Exterior Ballistics_, especially Chapter 8 and the MCTRAJ Q-BASIC
reference program.

- PDF copy used during research: [Modern Exterior Ballistics PDF](https://www.mori.bz.it/Balistica/Mc%20Coy%20Modern%20Exterior%20Ballistic.pdf)
